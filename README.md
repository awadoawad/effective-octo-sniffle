
# OpenVRD Engineering

An open-source engineering toolkit for civil engineers,
infrastructure designers and urban hydraulics specialists.

## Mission

Make civil engineering calculations, infrastructure
design tools and engineering automation accessible
to professionals, researchers and students worldwide.

## Development Roadmap

- [ ] Stormwater management and hydrology
- [ ] Hydraulic network calculations
- [ ] Retention and infiltration systems
- [ ] Road design and accessibility
- [ ] Earthworks and quantity estimation
- [ ] AutoCAD and DXF automation
- [ ] AI-assisted engineering workflows
- [ ] Technical documentation and examples

## Technologies

- Python
- NumPy
- Pandas
- SciPy
- Matplotlib
- ezdxf
- Streamlit

## Contributions

Contributions from engineers, researchers and
developers are welcome.

## Disclaimer

Engineering calculations must be independently
verified by qualified professionals before use
in real-world projects.
